1. RECOPILACIÓN Y SEGURIDAD DE DATOS (PREGUNTAS GENERALES)

- ¿Tu aplicación recopila o comparte alguno de los tipos de datos de usuario requeridos?
  -> SÍ (debido a la integración del SDK de Google AdMob).

- ¿Todos los datos recopilados por tu aplicación se cifran en tránsito?
  -> SÍ (Google AdMob utiliza conexiones seguras HTTPS).

- ¿Proporcionas a los usuarios una forma de solicitar que se eliminen sus datos?
  -> SÍ (los usuarios pueden reiniciar todos sus datos y progreso desde Ajustes -> Privacidad y datos -> Reiniciar mi progreso, y al desinstalar la app se eliminan todos los datos locales).

   - ¿Se recopila, se comparte o ambos? -> Recopilado y compartido (por el SDK de AdMob).
   - ¿Se procesa de forma efímera? -> No.
   - ¿Es obligatorio u opcional? -> Obligatorio (para el funcionamiento de los anuncios).
   - Fines de la recopilación:
     [X] Publicidad o marketing
     [X] Analítica

   - ¿Se recopila, se comparte o ambos? -> Recopilado.
   - ¿Se procesa de forma efímera? -> No.
   - ¿Es obligatorio u opcional? -> Obligatorio.
   - Fines de la recopilación:
     [X] Analítica
     [X] Prevención de fraudes, seguridad y cumplimiento

C. Ubicación (Aproximada):
